Questions We Cannot Answer

csgopolygonmirror.com is not PLG.BET support. The editors cannot see player accounts, balances, deposits, withdrawals or bonus status. Questions about a PLG.BET account go to support on the official PLG.BET site.

The editors never ask for a Steam password, a Steam Guard code, a Web API key or a PLG.BET login. Any message that asks for those details in the name of csgopolygonmirror.com is a scam.
